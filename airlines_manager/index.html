Optimisation settings

Scenario A: Complete selected-hub schedule rebuild. All usable aircraft models are evaluated. A380-800 uses fixed 852E + 4C. A350-900ULR uses fixed 430E + 1C. Other passenger aircraft use automatic Economy-first configurations. Dedicated freighters use cargo-only configurations based on whole tonnes of payload. Every rotation group contains seven identical aircraft with the same configuration. Total daily demand is shared across all proposed groups. BKK, CGK and DEL remain excluded as destinations. Hubs are discovered automatically from the route and pricing datasets; demand is optimised separately for each hub.
