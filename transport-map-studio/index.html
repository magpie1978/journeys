Transport Map Studio — Multi-Bend Geometry Lab v0.2.1

Consecutive bends · true concentric offsets · invalid-geometry detection · 259 automated checks

Bend radius is never silently changed. If adjacent fillets cannot fit, the geometry is rejected. 180° hairpins and automatic service splitting are not included in this release.

Each bend is a circular arc tangent to its incoming and outgoing segments. All strands are offsets from one centreline. This lab tests geometry, not service merges or intersections between distant parts of a route.
