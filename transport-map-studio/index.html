How frequencies work

Each strand is a true normal offset from a shared centreline. 45°, 90° and 135° changes of direction are permitted as smooth circular bends. Every strand uses the same tangent layout and a concentric radius. If a bend cannot fit, the editor reports it rather than drawing a sharp corner.

Version 0.2.3.2

Station ticks and interchange bars, label positioning and rotation, draggable route handles, and zoom-to-fit. Maximum turn 45° in default mode; invalid station and bend movements are blocked. Automatic service merging is not yet supported.
